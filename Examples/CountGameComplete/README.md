# 完成版を動かしてみよう！

このフォルダには、5つのTutorialを最後まで進めた完成版が入っているよ！

1. `CountGameComplete.xcodeproj` をXcodeで開こう。
2. 実行先にiPhone Simulatorを選ぼう。
3. ▶︎を押すと、すぐゲームを試せるよ！

`ContentView.swift` の下には「赤の番」「青の番」「ゲーム終了」の3つの
`#Preview` があるよ。Canvasを開くと、操作しなくても大事な画面を確認できるよ！

## メンター向け60分ガイド

- 0〜10分：上下のフィールドと中央カードを作ろう！
- 10〜20分：1・2・3のボタンをゲームらしくしよう！
- 20〜35分：1回だけ使える「5とる」を追加しよう！
- 35〜50分：音、振動、数字の動き、紙吹雪を追加しよう！
- 50〜60分：リセットと3つのPreviewを確認しよう！

途中で困ったら、Tutorialのコード差分と各章の完成画像を見てみよう。
完成版を別ウインドウで開いておくと、受講者へゴールを見せやすいよ！
