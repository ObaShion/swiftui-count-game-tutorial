# 数取りゲームをもっとゲームらしくしよう

@Metadata {
    @TechnologyRoot
}

中高生向け SwiftUI 教材です。17個の数字から赤と青が交互に数字を取り、最後の数字を取って `0` にした人が負けになります。

すでに動いている `ContentView.swift` を少しずつ改造して、60分でゲームらしい見た目、スペシャルワザ、音と演出を追加します。
